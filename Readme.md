 STEAM Who?

Questa opzione, adatta a tutti gli indirizzi scolastici, prevede la realizzazione di un’applicazione 
Web che sia in grado di riconoscere e indovinare, a seguito di una serie di input, un personaggio famoso 
appartenente all’ambito STEAM tra i possibili elencati. Il sistema dovrà essere sviluppato in modo tale 
da porre all’utente una serie di domande chiuse, alle quali si potrà rispondere o affermativamente o negativamente; 
analizzando il susseguirsi delle risposte date, il sistema dovrà essere in grado così di determinare di quale
personaggio si tratti.
